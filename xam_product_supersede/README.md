# Product Supersession & Replacement Management

Manage product supersession, replacement chains, and interchangeable products in Odoo.

## Features
- Supersedes / Superseded By / Interchangeable relationships
- Automatic reverse relationship handling
- Cycle prevention
- Effective & expiration dates
- Product form integration
- Replace obsolete products in quotations
- Multi-company support
- Chatter tracking

## Supported Versions
- Odoo 17.0
- Odoo 18.0
- Odoo 19.0
